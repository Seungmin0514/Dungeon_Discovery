2024년도 하반기에 진행된 Dungeon_Discovery 프로젝트에 대한 내용입니다. 
unity로 진행된 Dungeon_Discovery는 로그라이크장르의 게임으로 단순히 아이템을 획득하여 캐릭터를 강화하여 몬스터를 물리칠수 있습니다. 최종적으로 보스를 물리치는 것을 목표로 합니다.
Dungeon_Discovery만의 특이한 기능은 공격방식입니다. 캐릭터를 중심으로 주위에 키보드 자판이 랜덤하게 떠있습니다. 플레이어는 해당하는 키보드 자판을 눌러 해당방향으로 공격을 할 수 있습니다. 추가적으로 붉은 자판은 떠있는 자판중 랜덤하게 지정되며 그자판을 누를시 강화 공격이 사용되고 다른 자판으로 붉은 자판이 지정됩니다.
기본적인 조작법은 wasd로 캐릭터를 움직일수있고, 화면에 표시된 자판을 눌러 공격을 할수 있습니다.
포션 아이템을 먹으면 체력을, 다른 음식아이템을 먹으면 공격력,이동속도,공격속도 등 특정 스텟이 올라가게됩니다.
